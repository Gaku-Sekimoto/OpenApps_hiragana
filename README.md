# ひらがな すいすい

タブレットやスマートフォンの指操作で、ひらがなをなぞって練習するHTMLアプリです。

## 使い方

`index.html`、`style.css`、`app.js` の3ファイルを同じ場所に置き、`index.html`をブラウザで開いてください。外部ライブラリや音声ファイルは不要です。

GitHub Pagesで公開する場合は、このフォルダのファイルをリポジトリのルートにアップロードし、リポジトリの **Settings → Pages** から公開元のブランチを選択します。

## 主な機能

- あ行からわ行まで、行単位で練習
- 書き順の番号ガイド
- 指・ペン・マウスでのなぞり書き
- 完了時の正解音と紙吹雪
- 端末内への進捗保存
- タブレット・スマートフォン対応
